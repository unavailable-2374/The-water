# TEST 设定的真实输出：人工匿名评阅

A.txt 与 B.txt 均由 Lunaroute `deepseek-4.1-flash` 在固定的 TEST 虚构设定下实际生成。正文未经编辑。TEST 只标识虚构测试输入；它不表示正文由脚本模拟。请在打开 `observed-runs.json` 或实验日志前完成评分；候选映射保存在评阅目录之外，manifest.json 记录了封存 hash。

先读相邻目录的 `TEST-input.json`，再依次读 A.txt、B.txt。只根据文本判断，不猜测实现方式。每项分别给 A、B 打 1–5 分，并指出至少一处原文作为依据：

| 维度 | 1 分 | 3 分 | 5 分 |
| --- | --- | --- | --- |
| 情节成立程度 | 关键结果缺少原因或前提 | 主线可成立，局部靠巧合或解释补齐 | 行动、阻力、选择与结果有清楚因果 |
| 人物可信度 | 行动违反目标、动机或红线且无解释 | 大体可信，部分转变缺乏铺垫 | 动机、代价、声音与转变均有文本支持 |
| 连续性 | 知识、时间、规则或结局存在明确矛盾 | 没有根本矛盾，但交接含糊 | 知情边界、时空与规则跨章一致 |
| 表达 | 重复、空泛、对白同质，明显妨碍阅读 | 可读，有冗余或局部失衡 | 清楚、具体，对白和动作承担叙事功能 |

另请记录：明确的设定冲突（原文 + 违反哪条输入约束）；整体偏好（A / B / 相当）；判断把握（低 / 中 / 高）。不要把文字长短、术语多寡或模型自评分单独当作品质证据。

可直接回复：`A：情节__，人物__，连续性__，表达__；B：…；偏好__；把握__；原文依据…`。

这是同一组输入下、从开发记录中各选一份样稿的探索性比较。开发中进行了多次运行与修复，样稿选择存在偏倚；匿名映射只减少评阅时的身份线索，不能消除选择偏倚。即使一稿得分更高，也不能据此声称普遍提升或统计显著。评分前不揭盲；缺少人工评分时，质量结论保持“未评定”。
