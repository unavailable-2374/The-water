## 真实模型过程

调用 `https://gw.lunaroute.com/v1` 的 `deepseek-4.1-flash`，沿用项目供应商配置：上下文 1,048,576，供应商最大输出 262,144，推理预留 32,000，reasoning effort 为 low，JSON Schema 模式。探索默认 moderate，产品请求初始正文输出预算上限 14,000；JSON 修复及预算行为沿用现有请求层。密钥只由环境提供，不进入记录。

所有已落盘的运行保留，以下文件名不是质量等级：

1. [最初请求](story-options-real-20261010.json)：环境凭据收到 HTTP 401，未生成候选。使用项目 `.env` 中可用凭据后认证通过，未将密钥写入聊天或仓库。
2. [配置后请求](story-options-real-20261010-configured.json)：候选与比较成功，计划 JSON Schema 的 `propertyNames` 被网关语法拒绝。模型输出结构随后移除受保护的风格、二创、称呼表字段，由源数据原样恢复。
3. [受保护框架检查](story-options-real-20261010-validated.json)：模型改写原框架，被校验拒绝。之后将 premise 也改为源数据原样保留。

## 文学内容检查（编辑判断，非客观评分）

四张卡的核心行为有差别：留下整理死信档案、烧掉副本后离岛、把船票交给母亲、交还原信放弃追问。比较忠实列出了得到与放弃，并识别“副本被烧但原信仍在，何以是唯一证据”等问题。差异仍集中在留岛/离岛、保密/追问，关系收束多为沉默与有限信任；不能据此宣称探索覆盖面或文学质量普遍提高。

TEST 作者动作固定选择第一个未被硬约束阻止的候选，不代表助手自行选卡。所选“死信柜里的十年”的计划保留了撕掉调职令、留岛接手档案、母亲健在、不依赖超自然、单夜推进以及沉默共处的方向。原始框架逐字保留。

仍存在具体文学缺陷：候选写十年前林舟十岁，计划却新增“三十岁上下”，年龄算术矛盾；第一场景写母亲在场，但结果又说“带着信去问母亲”，调度不够清楚；比较提出的十岁住县中学旧宿舍问题没有被充分解释。这些并未由结构校验自动排除。后续计划生成已接入比较建议，但该修改本身不能证明问题已经消失。最终质量仍须作者在差异审阅中判断，本次没有作者盲评、重复样本统计或普遍质量提升结论。
