# 按题材准备与试写

题材包是可组合的创作指导，作品已确认设定与主要阅读体验优先。都市描述生活环境，幻想描述世界条件，悬疑描述信息组织。选包不能自动确立境界、社会制度、凶手出场时机或叙述者可靠性。

在创作说明 readingExperience 写清主要体验与作品承诺，在 constraints 写需要守住的边界。准备结果放入分卷 summary、人物 description / 目标卡、具体 settings、伏笔 thread 和场景卡；规划不是已发生事实，真实发生的叙事事件由已提交正文证据维护。

| 方向 | 优先准备 | 试写片段检查 |
|---|---|---|
| 悬疑／推理 | 解谜、危机或心理关系重心；真实事件顺序与读者接触顺序；各人知情范围；线索、成立解释与替代解释排除 | 一条新信息是否有依据地改变判断或危险处境 |
| 都市 | 具体职业任务；钱、时间、权限、责任；人物利益与关系记忆 | 发现问题、判断、行动与结果能否可信地解决工作问题，并影响生计或关系 |
| 玄幻／仙侠 | 成长、探索、神话、权谋或日常重心；能力作用、条件、不能做什么、使用影响；修行意义与生活后果 | 利用既定能力作出的选择，是否同时带来新机会和后果 |
| 言情 | 为什么偏偏是两个人；独立目标、吸引依据、顾虑与相处方式 | 一次行动与回应能否增加理解，关系成立后怎样共同面对生活 |
| 科幻 | 核心假设、技术边界、人的行为与社会后果 | 技术条件是否改变具体人的选择与责任，而非只增加术语 |
| 历史／架空历史 | 当时可知信息、观念、组织资源与利益；具体史实核实；改变的实施条件 | 现代知识是否经过实际资源和组织执行，其他人物是否保留自身经验与利益 |
| 武侠 | 武力边界、恩仇、承诺与秩序冲突 | 能赢得战斗时，仍有什么必须作出的价值选择 |
| 日常／治愈 | 生活任务、独特相处、微小变化和情感基调 | 一件小事是否增加理解、陪伴感或生活改善 |
| 混合题材 | 主要体验与各元素依赖关系；稳定能力信息边界；职业权限与调查来源 | 同一事件是否共同推进职业判断、能力运用、调查和人物关系 |

## 悬疑的条件性公平

承诺读者参与破案时，解答应有此前可接触的依据，并说明其他解释为何不成立；动机只构成怀疑，识破手法也不直接确定实施者。危机型可以先告知凶手，心理关系型不强制提前推出唯一答案。不可靠叙述须有处境与心理依据，以及回看可理解的裂缝。

各阶段确认答案或排除解释，让答案改变处境并引出选择。读者猜中不是临时换答案的理由。未知真相不必提前泄露；未到规划回收时机，审稿不应催促揭密。

## 混合题材的接点

特殊能力提供的信息边界稳定；读到对方相信的事不等于知道客观真相，关键嫌疑人出现时不能方便地失灵。都市异能允许超自然条件，信息获取、介入理由、权限、信用、供货、团队和人际信任继续影响行动。扩大幻想世界时，旧能力、朋友、经验与承诺仍有价值；新阶段改变问题性质。

## 实现与边界

七个题材包保留既有六个稳定 ID，并新增 daily 日常／治愈。每包提供准备与试写提示、正文规则和质检重点；多包附加共同事件与稳定边界指导。全部所选规则进入大纲、章节表、滚动场景与正文，不按选择顺序截掉后选包；模型窗口不足仍显式报错。

通用题材词汇不再自动产生硬禁词，作者在作品文风档案明确设定的禁词仍有效。题材条目以「创作指导，非本书事实」标注；事实校对只对照本书已确认规则，题材重点进入叙事审稿并遵守证据与建议／阻断区分。旧作品已采纳的具体设定保留，由作者决定是否修改，不自动迁移或重写。

测试只验证资料与流程契约；本指南未包含真实模型生成或真实读者效果的验证结果。
