# 技术博客 / 技术文档

## 适用
面向开发者的教程、操作指南、参考、原理解释（Diátaxis 四象限），以及个人技术博客。

## 流程
1 立意：先定 Diátaxis 类型（教程=学习+动手、操作=任务+动手、参考=工作+认知、解释=学习+认知），一篇只做一种；TL;DR 三句。2 素材：可运行的代码、版本号、实测输出、引用来源。3 结构：倒金字塔（结论/结果前置）→ 前置条件 → 步骤/论述 → 陷阱 → 延伸。4 草稿。5 自审：每段代码能否复制运行、每个断言有无依据。8 校对：Google 开发者文档风格 + 中文文案排版指北。

## 骨架字段
文档类型、目标读者与前置知识、TL;DR、环境/版本、步骤（每步：目的 → 命令 → 预期输出 → 常见错误）、结论、参考链接。

## Prompt 要点
第二人称、祈使句、现在时；一段一件事；代码块必须完整可运行并标语言；不写"我们将在本文中…"式导语；术语首次出现给全称。

## 专属质检
代码块无语言标注、步骤缺预期输出、断言无来源、被动语态、`ai-tells.en.json` 命中（leverage/seamless/robust）、中英文间距与全角标点。
