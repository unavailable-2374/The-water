# 学术摘要 / 综述

## 适用
论文摘要、结构化摘要、文献综述、研究计划书的背景部分。

## 流程
1 立意：研究问题 + 缺口一句话。2 素材：文献表 `{引用, 方法, 结论, 局限}`。3 结构：摘要按 IMRaD 各 1-2 句（背景/方法/结果/结论，150-300 词）；综述按主题或方法分组 → 每组共识与分歧 → 缺口 → 方向。4 草稿。5 自审：每个结论是否对应一个结果、数字是否与原文一致。

## 骨架字段
研究问题、背景、方法（对象/设计/指标）、结果（含效应量与不确定性）、结论、局限、关键词；综述加：分组表、缺口、未来方向。

## Prompt 要点
不写文中没有的数字；被动语态在方法段可接受；避免"novel/首次/革命性"式夸大；结论不超出结果。

## 专属质检
结论超出结果、数字无出处、夸大词（novel/groundbreaking/首创）、缺局限段、引用格式不一致。
