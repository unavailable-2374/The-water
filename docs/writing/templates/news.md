# 新闻稿 / 通稿

## 适用
事实性报道、机构发布、活动通稿。

## 流程
1 立意：核心事实一句话（5W1H）。2 素材：事实核（时间/地点/人物/数字/引语，逐条标来源）。3 结构：倒金字塔：导语（≤60 字含 5W1H）→ 次要事实 → 背景 → 引语 → 补充。4 草稿。5 自审：任意从末尾删段是否仍成立。

## 骨架字段
标题（≤20 字，动词）、导语、事实列表（按重要性）、引语 `{人, 职务, 原话}`、背景、联系方式/发布机构。

## Prompt 要点
第三人称、过去时、无形容词评价、数字用阿拉伯数字、引语原样不改写；禁止"值得一提的是"。

## 专属质检
导语超 60 字、缺任一 W、形容词密度、未标来源的数字、引语无署名。
