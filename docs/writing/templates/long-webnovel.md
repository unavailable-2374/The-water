# 长篇网文

## 目标与适用

按章连载的长篇小说，规模由故事与作者能力决定。目标是让读者愿意继续读，也觉得已经读过的部分值得。成长、悬疑、关系、经营、日常可以组合，但应有稳定的主要体验；书名、简介与开篇应指向正文能长期提供的内容。

## 一页创作说明

在「创作资料 → 创作说明」填写；以下是待回答的问题，不是已经确定的故事事实。

| 问题 | 字段 |
|---|---|
| 主要阅读体验是什么，读者为什么持续回来？ | readingExperience |
| 主角是谁，眼前具体想要什么，全书长期追求什么？ | mainline；人物目标卡 goal |
| 有什么独特的做事方式，为什么换名字仍能认出本书？ | distinctiveApproach |
| 这种方式受到什么边界、资源和关系限制？ | protagonistLimits；constraints |
| 首个篇章作出什么重要选择？ | firstChoice |
| 选择怎样改变处境并引出下一步？ | choiceConsequences |
| 到什么状态故事结束？事件、人物与情感怎样完成？ | ending |

旧卡片缺失的新字段表示尚未指定，不能当作已确认事实。打开旧卡编辑时可补填；自动大纲先生成候选，采纳后才成为规划约束。

## 持续产生故事的分层规划

按[情节因果、人物与余味指南](plot-design.md)区分题材提供的体验与主题检验的问题。重要节点解释为何此时发生、谁的行动促成、结束后什么无法照旧；成功也可以通过责任与关系变化引出下一阶段。反转若有，同时重新解释旧细节并推动新选择。幸福、平静与阶段完成不因缺少意外而降低价值。

- 全书：长期目标、持续阻力、独特解决方式、主要转折、最终考验和结束条件。
- 当前篇章：目标、困难、关键选择、阶段结果与后续变化。篇章从行动 → 后果 → 处境改变 → 新选择延续，不能仅换地图、对手或数值。
- 临近章节：滚动规划最多五章的场景，写出行动、信息揭示与情绪积累；短篇规模不强凑三个篇章，长篇则检查主要篇章之间是否具有因果延续。

人物 description 与目标卡记录目标、害怕失去的事、信念、惯常解决方式、原则例外和价值冲突；重要配角应能回答「主角离开后，他会做什么」。成长可以改变自己，也可以坚持自己并改变环境。

具体按[角色卡的风格、复杂动机与自我保护指南](character-card.md#风格复杂动机与自我保护)构思：几种动机都可以真实，说明愿望与想保住的东西如何牵制，以及保护办法曾经带来什么、现在妨碍什么。通过关系不同、条件与代价递进的选择显出层次，不反复重置同一种不安，不把外部资源限制归为心理问题。保留日常快乐与轻松相处；创伤不是必填项，理解伤害的原因不抹掉受伤者的边界。

## 开篇与场景

开篇尽早交代跟随谁、眼前为何值得在意、作品独特之处和下一步期待，并呈现主要体验的一次真实样本。黄金三章可作经验，不设固定字数、固定爽点或统一悬念规格。秘密可以暂不揭露，眼前处境应清楚；设定只先解释理解问题所必需的部分。

场景卡使用现有字段，不额外维护一套重复记录：

- goal：人物想要什么，读者此刻在意什么。
- obstacle：持续阻力与人物可知的信息；为什么不能用明显更简单的办法。
- turn：关键选择、发现、理解或关系变化。
- outcome：实质变化、阶段满足与引出的后果。
- time / location / characterIds / dependencyIds / threadIds：时空、参与者、既有依据与伏笔引用。

平静的做饭、修物、讨论和相处可积累感情；无需每场战斗或反转。章末可以是悬念、决定、关系变化或余味。阶段答案、胜利和关系进展不应反复撤回。

## 三份持续记录与结尾

1. 人物与关系：目标卡、人物关系及已提交正文的 relationship / knowledge 事件，记录谁知道什么、欠谁什么、信任怎样改变。
2. 规则与时间：settings 与场景时空、已提交正文的事实/事件；能力边界、资源和行程应一致，重要制度应落实到普通人的生活。
3. 期待与伏笔：thread 卡规划 setup / progression / payoff / plannedChapterNo；真正埋设、推进与回收必须来自已提交正文证据。到期未收是复核线索，不按固定章数自动判错。

后段让已有选择产生结果，让既有角色、关系、规则参与解决。结尾分别检查核心事件处理、主角最终选择和重要关系的情感回应；开放结局可留世界继续运转，但应完成这段故事。

## 写作与审稿

大纲、章节表与滚动场景规划注入同一份长篇指南；创作说明随已确认资料进入正文上下文。正文保持因果、知情边界、指代、动作空间、对白区别和稳定语气，重要场景展开、过渡概述。

审稿检查阅读体验、阶段兑现、人物主动选择与后果、规则影响、伏笔依据和结尾回应。体验与节奏不足给建议；仅可证实的设定、人物红线、知识或时空冲突可阻断，所有问题须有逐字正文证据。规划不能冒充既成事实，未到回收时机不催促揭密。

## 连载复盘

试读时询问「哪里开始想继续看、哪里想跳过、主角最想做什么、哪个行为不可信、最想知道什么」。区分反馈的感受、归因与方案，先定位根因再修改。更新计划要包含构思、研究、修改与休息，保留存稿与规划缓冲；先完成可驾驭的完整篇章再扩大规模。

上述复盘由作者和真实试读者执行；自动化契约测试只验证字段与流程，不能证明追读或文学质量提升。
