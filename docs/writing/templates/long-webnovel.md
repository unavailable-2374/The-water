# 长篇网文

## 适用
50 万字以上、按章连载、读者追更。The-Water 的主流程（大纲 → 章节表 → 逐章写作）就是为它设计的。

## 流程（映射九阶段）
| 阶段 | 本类型做法 | 产物 |
|---|---|---|
| 1 立意 | 雪花法①②：一句话 + 一段话（背景 + 三次灾难 + 结局）；题材定位：核心消费点（爽/甜/虐/悬）、金手指、读者预期 | `Brief`（premise + themes + 消费点） |
| 2 素材 | 雪花法③⑤⑦：主要角色 GMC → 小传 → 完整角色卡；世界观 lorebook；StyleProfile（预设或从范文提取） | characters / settings / styleProfile |
| 3 结构 | 三层：卷纲（每卷爽点阶梯、情绪走向、伏笔登记）→ 章纲（ChapterPlan：目标/情节点/视角/钩子）→ 场景卡；黄金三章单独细纲 | arcs / chapters / scenes |
| 4 草稿 | 现有 writeChapter；分前后半 | 章节正文 |
| 5 自审 | 爽点是否兑现、钩子是否成立、节奏（高压 > 3 章或平淡 > 2 章报警）、人物偏离、AI 味 | IssueList |
| 7 修订 | 定点 revise | — |
| 9 提交 | summarizeAndBible + 伏笔债务更新 | commit |

## 骨架字段
- **题材定位**：题材/子类型、核心消费点、金手指、目标平台与读者画像、对标作品 2 部。
- **卷纲**（每卷）：卷目标、开卷状态 → 结卷状态、爽点阶梯（3-5 个递增）、情绪曲线、本卷埋/收伏笔、本卷新增势力/地图。
- **黄金三章细纲**：第 1 章 300 字内出主角与冲突、第 3 章前给第一个爽点、每章末钩子类型。
- **伏笔债务表**：`{id, 埋于章, 内容, 计划回收章, 状态: open/advanced/paid, 陈旧度}`。
- **节奏表**：每章标 高压/推进/缓冲，连续同类报警。

## Prompt 要点
- 大纲 prompt 要求输出 Schema 校验的 JSON（现有 outline/chapterTable）。
- 写章 prompt 注入：本章场景卡 + 命中的 lorebook + 相关角色言行规格 + StyleProfile 摘要 + 2-3 段示例 + 负面清单 + 最近 2 章摘要 + 前一章末 500 字。
- 升级/战力/货币等数值写进 lorebook `rule` 条目并常驻。

## 专属质检
爽点兑现率、钩子类型是否连续重复、伏笔陈旧 > 20 章、战力/数值一致、章首环境定调是否每章雷同、`lexicon/ai-tells.zh.json` 网文套话（眼底/嘴角）。
