# 情节设计：因果、人物与余味

“高级感”落实为因果扎实、人物具体、事后有余味。阅读中有期待，转折可以意外，回看又能理解此人为什么走到这一步。爽文、甜文、喜剧、幸福结局、明确善恶与清晰故事线都能达到高完成度，不用苦难、晦涩或反转数量替代判断。

## 题材与主题

题材决定需要提供什么体验；主题是人物重要选择反复检验的问题。例如，成长可以问旧办法什么时候需要调整，自由可以问人物是否愿意承担自己选择的后果，正义可以问正确决定造成的具体损失由谁承担。主题通过局势、行动和后果呈现，不要求唯一答案，也不靠哲理台词代替检验。

## 规划顺序与保存位置

| 顺序 | 需要写具体的内容 | 现有字段 |
|---|---|---|
| 1. 阅读期待 | 主要体验、混合题材的次要重要承诺 | brief.readingExperience；themes 可写主题问题 |
| 2. 人物办法 | 目标、惯常处理方式、收益与限制 | 人物 goal、habitualStrategy；brief.distinctiveApproach、protagonistLimits |
| 3. 持续后果的选择 | 事件和决定分别是什么，谁承担代价，什么无法照旧 | 场景 choiceReason、choice、consequence、beforeState、afterState |
| 4. 节点因果 | 为什么此时发生、谁促成、改变决定后续会怎样 | brief.storyEngine；arc.summary；beat.summary；场景 obstacle、turn、outcome |
| 5. 结尾兑现 | 已有能力、准备、关系、规则与行为变化怎样参与解决 | brief.ending、endingConditions；人物 arc、growth；伏笔 setup、progression、payoff |

这些是构思问题，不是新增数据字段。各输出结构只填写自己允许的字段，旧资料缺失处保留待定。主题可写在已有的 themes 或摘要中，不建立与正文、地图并行的另一套大纲。

## 因果主干与累积

重要节点按“此前条件 → 判断与行动／外部变化 → 结果 → 持续后果 → 新选择”组织，避免仅用“接着”串联事件。主角的决定可以制造困难，世界也能独立带来灾难；不强迫所有事情由主角造成。偶然能开启故事，不反复代替关键解法的依据。

可选的生长方式是“旧办法有效 → 成功带来新处境 → 新条件暴露局限 → 重新选择”。人物可以坚持核心信念，只调整理解与实践。对手和配角维护自己的利益，检验方案、谈条件、回应局势；正常人的局部合理选择也可能组合成困难。

胜利可以留下资格、依赖、承诺、暴露、责任与关系变化，代价也可以是时间、便利、隐私、独立性或退路，不强制死人、惩罚胜利或撤回幸福。连载先完成阶段问题，再让后果推动下一阶段；安排消化、恢复与日常互动，避免换地图、等级或对手后清零。

## 反转、细节与结尾

若使用反转，检查两个方向：它重新解释哪些此前真实呈现的细节？它迫使人物改变什么判断和行动？反转可以是动机、关系或目标的变化，无需不断换凶手；不能临时补关键人物、万能能力或此前不可知的规则完成解法。

少数重要道具、台词、习惯、地点可以从生活感进入关系，再参与选择与解决。控制密度，普通细节可以只承担气氛。结尾调动已建立的能力、准备、关系、规则与行为变化，回应主要事件、人物选择与情感承诺。开放结局可以留下世界继续运转，不能靠突然否定铺垫制造意外。

## 按阅读承诺选择题材重心

| 题材／体验 | 情节重点 | 核对问题 |
|---|---|---|
| 悬疑 | 实际发生、人物判断、读者知情分开；线索改变判断，判断影响行动。公平解谜需提前适当呈现关键证据；心理惊悚可先让读者知道危险。 | 揭晓怎样重新解释旧细节？作案方式、机会、时间线与证据链是否完整？人物认识变化不能代替证据。 |
| 玄幻、仙侠 | 力量边界影响胜利方式；准备、合作、规则理解参与解法；传授、交易和机会分配影响制度与日常。 | 拿掉临时新能力，既有经历还能发挥什么作用？合作胜利如何回应此前个人夺冠的承诺？ |
| 都市、职场 | 信息、利益、决策权限、失败责任与资源流程参与产生和解决问题。 | 方案难落实在哪里、影响谁？具体行业流程是否已核实？身份或天才方案不能自动抹去执行过程。 |
| 爱情 | 吸引发生在共同经历中，通过真实愿望、边界和行动变化推进；理解之后仍需练习新习惯。 | 删掉告白，哪些行为仍显示关系变了？误会为何没说清、沟通代价是什么？甜文无需强制信任崩塌。 |
| 历史、权谋 | 资格、组织执行、钱粮运输时间、信息缺口与联盟条件共同塑造局势；对手会利用变化。 | 配角认真维护自身利益，计划如何成立？判断依据与调整是否可见？具体史实需核实，架空制度也有约束。 |
| 科幻 | 从已确认假设推演便利、新问题、受益者与难适应者，进入工作、关系和日常决定；规则保持一致。 | 去掉假设，核心冲突还成立多少？保留、遗漏、同步等限制是否影响行动？不强迫新增技术。 |
| 恐怖 | 某种熟悉安全感逐步失效；异常、感知、调查、逃离和求助都有连贯后果。 | 每次异常后失去了什么依靠？惊慌、冲动和误判是否有来源？解释可留白，危险与行动后果仍需一致。 |

混合题材先明确主线，认真处理已经积累的重要承诺。日常可以用小动作兑现长期情感，喜剧可以依靠精确的信息错位和人物回应收束。指导按本书承诺适用，不自动成为本书设定。

## 审查边界与常见桥段复核

反转多、人物惨、人人有悲惨过去、时间线复杂、哲理台词多、故意让期待落空，都不能自动证明完成度。反派可以简单自私，幸福也可有充分过程。审稿检查具体因果、行动与后果，不能因线性叙事、熟悉桥段或明确善恶判错。

对退婚、夺冠、重逢、破案等桥段问四件事：这个人为什么卷入？他会用什么自己的方式处理？这种方式制造什么新局面？事情结束后什么无法照旧？这是复核方法，不是必须插入的剧情。

文学建议须有具体材料依据与修改目的；缺失资料、明确矛盾和审美选择分开。仅因未遵循某种写法不得阻断，真正的因果缺环或已确认事实冲突按既有修订与门禁契约处理。不到兑现时机不催促揭晓，不把未来后果当成正文事实。
