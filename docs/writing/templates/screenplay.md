# 剧本（影视/短剧/舞台）

## 适用
以场景（scene）为单位、对白与动作为主、无叙述者的文本。

## 流程
1 立意：log line（Dramatron 起点）。2 素材：角色描述（Dramatron 第二步）。3 结构：按观看体验选择三幕、八拍、片段或单一情境结构，再标页数/分钟 → 场景清单（scene list）→ 每场一张场景卡。4 草稿：按场景生成，格式为 场景标题（INT/EXT · 地点 · 时间）/ 动作描述 / 人物名 / 对白 / 括号提示。5 自审：每场是否推进信息、关系或日常积累；对白是否服务相处与当下行动，不把普通闲聊一律删掉。

## 骨架字段
log line、观看体验、所选结构、结束条件、场景清单 `{编号, INT/EXT, 地点, 时间, 人物, 目的, 转变, 页数}`。

## Prompt 要点
禁止叙述者；情绪只能通过可拍摄的动作与对白表达；动作描述用现在时短句；场景长度按作用与节奏安排，不设统一页数门槛。

## 专属质检
场景未服务本篇体验、对白与当前关系或行动冲突、括号提示过多、时间线跳跃未标注、人物在同一时间出现两地。
