# 剧本（影视/短剧/舞台）

## 适用
以场景（scene）为单位、对白与动作为主、无叙述者的文本。

## 流程
1 立意：log line（Dramatron 起点）。2 素材：角色描述（Dramatron 第二步）。3 结构：三幕 + Save the Cat 15 拍标页数/分钟 → 场景清单（scene list）→ 每场一张场景卡。4 草稿：按场景生成，格式为 场景标题（INT/EXT · 地点 · 时间）/ 动作描述 / 人物名 / 对白 / 括号提示。5 自审：每场是否改变局面、对白是否可删（删了不影响就删）。

## 骨架字段
log line、主题陈述台词、情节点 1/2、中点、B 故事（关系线）、场景清单 `{编号, INT/EXT, 地点, 时间, 人物, 目的, 转变, 页数}`。

## Prompt 要点
禁止叙述者；情绪只能通过可拍摄的动作与对白表达；动作描述用现在时短句；每场 ≤ 3 页。

## 专属质检
场景无转变、对白直接说主题、括号提示过多、时间线跳跃未标注、人物在同一时间出现两地。
