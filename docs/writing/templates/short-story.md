# 短篇小说

## 适用
3 千 - 3 万字，一次读完，结构靠一个"故事核"和一次反转撑起。

## 流程
1 立意：故事核一句话（谁 + 想要 + 但是 + 于是 + 最后）+ 情绪目标（读完让人感到什么）。3 结构：Save the Cat 压缩为 8 拍：开场画面 → 触发事件 → 辩论/决定 → 乐趣段 → 中点反转 → 逼近 → 灵魂暗夜 → 结尾画面（与开场画面呼应）。4 草稿一次成文或分 3 段。5 自审重点：反转是否早有伏笔、结尾画面是否回应开场。

## 骨架字段
故事核、视角与时态、开场画面、触发事件、中点反转、结尾画面、意象贯穿物（一个反复出现的物件/意象）、字数。

## Prompt 要点
StyleProfile 全量注入（短篇容得下）；要求"结尾画面必须与开场画面形成对照，但不许解释这个对照"。

## 专属质检
开场/结尾呼应、反转伏笔至少 2 处、无多余人物（出场人物 ≤ 5）、结尾不升华不总结。
