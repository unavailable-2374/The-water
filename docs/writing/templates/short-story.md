# 短篇小说

短篇的篇幅服务一次完整的阅读体验。结构方法由作者选择：单一情境中的逐步发现、决定与后果、环形或首尾照应、片段组合、多人视角、三幕或八拍。未指定时依据本篇阅读体验提出方法，不自动套八拍。

## 流程
1. 明确读完希望留下的感受、人物处境与结束条件。
2. 选择适合本篇的结构，在创作要求中保存；八拍是可选工具。
3. 通过动作、对白、注意力或相处权限的变化完成关键场面。
4. 检查正文能否支持读者理解重要选择；保留必要留白、普通闲聊与沉默。

## 骨架字段
主要阅读体验、人物处境、视角与时态、所选结构、关键选择或发现、持续后果、结束条件、篇幅参考。意象与首尾照应按需使用。

## 专属质检
按已确认体验与结构检查；不强制反转、暗夜、固定人物数量或总结性结尾。有反转时依据应可回看，不规定伏笔数量；开放结尾仍应让读者有依据理解本篇变化。平静与片段式作品不能仅因缺少反转判为缺陷。
