# 公众号推文 / 平台长文

## 适用
1500-4000 字，手机阅读，靠开头三段留人，结尾要动作。

## 流程
1 立意：一句话主张 + 读者痛点 + 标题 3 候选（数字/反差/悬念）。3 结构：SCQA 开头（情景 → 冲突 → 疑问 → 回答，≤300 字）→ 金字塔：3 个分论点，每点 PREP（观点 → 理由 → 案例 → 重申）→ 结尾 CTA。4 草稿。5 自审：三段内是否出现冲突、每个分论点有无具体案例、结尾是否只有升华没有动作。

## 骨架字段
标题、导语 SCQA、分论点 ×3（各带一个真实案例/数据）、金句 ≤2、CTA、配图位。

## Prompt 要点
段落 ≤ 4 行（手机屏）；案例要有人名/时间/数字；禁止每段小标题 + 每段等长；禁止"在这个…的时代"；金句不超过两处，否则变鸡汤。

## 专属质检
`ai-tells.zh.json` 全量（这是 AI 味重灾区）、段落等长、结尾升华、"不是…而是…"、案例无具体细节。
