# 故事线抽卡

适用于现有虚构文体。作者在整部作品、故事弧、章节或场景范围内探索四种走向，比较后选择方向，再审阅和整组采纳计划。正文不会因抽卡、选卡或采纳而改写。

## 入口与交互

- 新建作品：框架 → 创作参数与模型 → 故事线抽卡 → 确认创建。首次进入生成候选，也可明确跳过；非虚构沿用原规划流程。草稿自动保存，旧版草稿保留原输入并升级。框架改变会清除当前选择，但历史候选仍可查看。
- 作品规划页探索全书；故事工作台探索选定故事弧或场景；章节页探索当前章。
- 创作助手使用同一服务和卡片界面，只能生成、查看历史、保留、重抽和恢复请求。选卡与采纳必须由作者在界面执行。
- 每轮四张卡，默认适度探索，也可贴近原意或大胆探索。保留卡内容不变；补充偏好后重抽其余卡，或整批重抽。新组合重新比较。
- 卡片展开主线、冲突、选择与代价、成长、转折、结局及后续影响。比较展示冲突、人物、转折、情绪、结局和具体取舍，不使用客观评分。编辑建议与明确硬约束违规分别呈现；硬约束违规或必须扩大范围的候选不能选择。
- 抽卡独立生成，只使用作品框架（标题、故事前提、创作参数、目标字数）和本轮作者材料、偏好；已有故事线、人物卡、章纲、正文、图谱、作者附加指令及已采纳方向不自动进入请求。需要沿用的人物要求或局部起点须在材料框明确提供。全书默认重构；局部续写/重构仅用于选卡后的衔接校验，不用于带入旧故事。

## 数据与事务契约

共享类型位于 `packages/shared/src/storyOptions.ts`；业务入口位于 `apps/desktop/src/novel/storyOptions.ts`，持久化位于 `db/repos/storyOptionsRepo.ts`，整组采纳及撤销位于 `novel/storyOptionAdoption.ts`。

SQLite 第 13 版迁移保存会话、不可变候选、批次、请求阶段、比较、选择、生成结果、计划关联和带范围的作者决策。候选更新由数据库触发器拒绝。新建前归属向导草稿 ID，创建作品时与作品、风格、模型配置和草稿清理一同原子绑定，不提前建立空作品。

新批次保存模式、范围真实 ID、白名单作者输入、模型选择和作者输入摘要；抽卡不保存正文边界。选卡后另行读取实时作品上下文与正文边界，为待审计划记录完整作品摘要。选择、生成计划、采纳分别检查归属、锁定和依赖；采纳及撤销在写事务内再次比较依赖，防止校验与写入之间的并发覆盖。范围外实体、旧实体 ID、保存的正文与版本不被替换。新场景按模型返回顺序保存，并绑定真实章节。

模型先从作者输入规划四种行动策略与各自三至六个阶段目标、选择及后果，再按各自策略逐卡独立生成事件单元，原样组装唯一叙事，持久化后另行提取展示字段。全书 outline 原样保留叙事段落，转折必须逐字摘自指定段落并按先后排列；局部候选将完整叙事保存在 turns。摘要不得补造资源、动作或代价。叙事完成后提取失败，恢复时复用已保存叙事。各卡获得完整输出预算，使用单对象输出协议；生成每卡只发送自己的策略，不发送其他新卡的完整剧情或设计轴，避免前卡成为后卡模板。明确保留的卡与融合来源仍是作者主动选入的材料。候选先落盘，再逐卡完整审查，必要时进行有证据的定向修订与一次重新构建，最后独立比较两两差异；每卡经证据校验的审查进度先落盘，并绑定审查规则摘要，规则改变时旧缓存失效。比较失败恢复时不重复已完成且规则一致的单卡请求。选卡后另行生成待审计划。切页不取消请求；启动时将未完成阶段标记为可恢复。错误保留真实信息，不补造候选、比较或成功结果。用量经现有记录与预算检查，超出上下文窗口直接报错。

选卡产生一份包含大纲/章节计划/场景卡的文档计划建议，沿用差异审阅。所有变化只能整组采纳或丢弃。开始计划生成前暂停同作品活动写作任务并等待安全检查点；采纳沿用任务计划核对机制，由作者继续任务。只读探索不暂停写作。

采纳后方向进入后续任务、工作台和正文助手的上下文。子范围遵守父范围明确约束；修改相关计划、框架或作者附加指令会标记待复核。同范围重新采纳会将旧方向标记为已替代；旧记录仍保留，撤销整组时恢复此前决策状态。撤销若发现作品在采纳后已变化，会拒绝覆盖。

探索历史随数据库备份保存。公开创作材料仍只走既有已采纳计划协议，不把探索批次或未采纳方向加入公开材料。

## 边界与代价

普通四卡每轮基础十四次模型调用（一次策略规划、四次叙事生成、四次展示字段提取、四次单卡完整审查、一次六组差异比较）；每个未保留的新草稿至多两次叙事修订、重新提取与各自重新审查，因此完成全部差异比较前最多三十八次，关键缺口尚未解决时提前停止差异比较。单卡融合基础三次，含两次叙事修订、提取与复审最多九次；选择后至少再有一次计划调用；网络或 JSON 修复可能增加调用。未保留的旧批次不会删除。抽卡的过期检查只跟踪作品框架及本轮明确输入，修改已有计划或正文不会影响独立抽卡。选卡后生成的待审计划仍使用完整作品摘要做并发校验，采纳与撤销不降低保护。

字段、ID、范围和并发校验不能证明文学质量；模型比较也可能遗漏因果、年龄或时间线问题。作者必须审阅计划。真实模型检查的具体观察和未解决文学问题见 [验收记录](evaluation/story-options-20261010.md)。支持作者指定多卡融合；没有随机稀有度或奖励机制。


## 大纲优先（2026-10-10）

规划页的「重新构思」直接打开全书大纲抽卡，暂停或等待审阅的写作任务不阻止只读探索。新建作品及全书抽卡每轮提供四个从开端到结局的完整大纲，包含 4–16 段因果发展；不是若干故事节点。全书入口默认重新构思，局部入口仍可续写或重构。旧版候选保留，缺少完整大纲时明确提示重新抽取。

选定全书大纲仅生成待审大纲；整组采纳更新故事弧和主要情节点，将章节计划标为待重新规划，保留现有章节、场景和正文。作者再单独生成章节表并审阅，之后继续写作。计划可在写作暂停或等待审阅的安全检查点生成，存在未审规划任务时仍阻止并行规划。

重生题材明确区分前世记忆与今生实物，不能把重生点之后才收集的证据当作当前时间线已存在的物证。实际作者材料的修正仍须作者明确采纳。


## 独立输入与证据化比较（2026-10-10）

整批重抽不发送上一批候选；保留重抽只发送作者明确勾选的卡片。生成与比较阶段均采用输入白名单，不发送整个数据库依赖签名（签名中含旧故事文本），也不发送未保留候选。助手入口遵循同一服务，并要求只转述作者本轮明确材料，不从助手已读取的旧故事补入条件。旧批次原样保存并标明曾使用旧故事线；旧批次未完成阶段必须重新独立抽卡，不能恢复污染上下文的生成。

候选生成要求摘要、选择代价、成长和结局在 outline/turns 中有对应事件；高潮说明准备、权限、资源与对手回应；明确人物和关系要求落实成行动。比较必须覆盖字段/时序、因果、人物要求、兑现和候选差异五项。发现分为明确输入违规、候选内部矛盾、信息待补和编辑建议，引用必须逐字存在于候选对应字段；硬约束另须逐字引用本次作者输入。整体状态由程序根据逐项发现汇总，不让模型同时写出“全部通过”和违规项。字段与引文校验不等于验证模型的语义判断或文学感染力。

全书重构选卡后可调整未锁定的旧人物与设定，保持实体 ID；旧人物卡、章节和正文的同步影响列入待审计划。局部衔接仍保留范围外事实与锁定，不能为了适配旧计划悄悄改掉作者所选方向。


## 差异化与多卡组合

四卡分别展示因果主干、关键选择及代价、高潮解决机制。生成结构要求三轴中至少两项不同且不重复整段大纲，比较阶段覆盖全部六组两两关系，要求至少两个不同设计轴的逐字引用和语义解释；换词不算新机制，作者固定的事件和结局可共用。被评为仅装饰差异或无法确认差异时，真实报告与候选仍保存，但批次标为失败、不能选择，须修改输入或整批重抽。融合卡无四卡差异门槛，改为审查来源取舍。这些校验能阻止结构重复，不能证明所有措辞差异都是真正的文学差异。

作者可勾选同一批次两到四张卡，输入想保留的部分，生成一张新的完整融合卡。程序只传选中的卡与明确作者输入；保留来源 ID 和来源批次，原卡不可变。模型须处理互斥身份、资源、事件先后和结局，重建统一因果并说明取舍，不能机械串联多个高潮。融合卡单独比较与审查，再走正常选择、待审计划和整组采纳流程，融合本身不改作品。融合批次只有一张卡，普通批次仍是四张；整批重抽始终重新独立生成四张。融合生成及比较失败保留真实错误与已持久化阶段，可恢复，重复请求不会重复生成。


## 从真实卡片缺口建立事件审查（2026-10-10）

最新四卡暴露的根因不是摘要字段不足，而是审查以摘要自证、关键缺口仍可进入 ready。生成规则现要求按文体、目标篇幅与范围组织阶段结果及后续局面；重要阅读承诺在事件中兑现；人物起点、关系变化、损失对象提前进入行动；高潮资源、权限与规则交代取得和触发；胜利留下实际持续后果。规则适用于不同题材，不写入这四张卡的剧情、人物或特定解法。生成拆为事件叙事与提取两阶段，避免多个字段独立编写导致摘要与大纲漂移；模型按策略阶段逐组返回事件，每组对应一个阶段；程序依据分组位置赋阶段编号，避免模型猜测索引。全书每阶段至少两个事件，局部每阶段至少一个，合计段落上限不变；阶段顺序与覆盖由程序校验，不接受复制事件凑数或同一句填不同字段。事件包含处境与注意力、具体选择、他人自主回应、实际结果和持续变化；关键资源另说明持有人、取得路径、交换条件、权限边界和触发，普通行动可不列资源。各项完整叙事句原样组成段落，不让摘要补足。事件单元与组装叙事分别保存，断点恢复复用完成的部分。结构存在不证明逻辑正确，仍须事件审查；提取和审查使用较低温度，创作阶段仍按作者探索幅度设置。

独立候选使用单独的 OUTLINE_EXPLORATION_RULE，共用人物与情节的创作方法，但不携带维护既有作品时的“不得新增设定/事件”“缺失内容标待定”限制。未知人物、关系、行业与取得路径允许合理构思，明确属于未采纳方案；作者核心目标须实际设计完成。选卡后的计划与采纳仍使用原有框架、事实、锁定与范围保护。审查/提取只读候选，不借创作许可补造证据。

作者的内容、风格、范围、偏好以及经审查得到的定向修订要求，作为授权创作任务参数单独传递；授权限于创作内容，不覆盖系统身份、输出协议或工具权限。候选草稿与其他材料仍使用资料隔离，避免把其声称已通过或外部指令当作作者要求。

新比较增加 qualityAudit 五项：范围与阶段推进、重要承诺兑现、人物与关系过程、高潮准备与生效、已发生的持续后果。通过判断必须逐字引用 outline/turns 中的事件；引用 design、growth、ending 的声明不能自证。模型只返回候选及作者片段编号，程序从目录还原对应字段原文；设计栏问题可以引用其实际设计字段，不能把作者输入或其他字段冒充大纲事件。事件与说明栏分目录、分别连续编号；事件目录按原大纲段落和转折完整取文，每项审查最多引用四段，不拆成重复句子目录、不补造证据。模型为 findings 标注所属检查点，程序依据非 editorial 问题分组，计算 gap、关联下标及阻断状态；模型无需维护数组索引，也不能在承认关键缺失后自行声明通过。关键 gap 必须关联本卡 findings 中真实的非审美问题；覆盖五个不同检查点、引文位置和关联索引由程序验证。模型仍负责判断证据是否足够，程序不能证明其语义判断正确。

出现明确输入违规、真实内部矛盾或事件审查关键 gap 时，仅对本轮尚未完成、作者未保留的新草稿先进行一次定向修订并重新独立审查；若仍有关键缺口，再依据作者输入、自己的策略与真实问题重新构建一次，不再以有缺陷旧稿为模板，随后再次独立审查。修订新增候选 ID，原稿与真实报告不可变保留，原稿只作修订材料而非已确认故事事实；作者已保留卡不自动重写。仍有关键缺口时保存报告，将批次标为 failed，阻止选择与融合；界面展示检查点、事件引文、缺口及修改方向，不能通过单纯重复审查掩盖已有报告。一般细化空间、审美偏好只作编辑建议，不阻断。所有非 editorial 问题均阻断，必须关联至少一个 gap；一般细化空间归为 editorial，不用 missing_information 混入关键缺口。审查的是大纲事件级因果，不要求执行日志、逐项技术保全记录或完整正文；普通细化空间不应升级成关键缺失。全批次严格门槛会增加重抽需求，避免把有问题的卡与正常卡共同标成已完成候选；不保证文学质量。

旧卡与旧报告保持可读、不追溯改写。多卡融合和局部探索共用新审查；局部范围允许有理由的不适用，不强制全书成长、国际化、感情线或悲剧。独立输入白名单与采纳并发保护不变。

可重复的真实模型评估位于 apps/desktop/test/evaluation/realStoryOptionQuality.test.ts：在隔离 TEST 数据库复审原四卡，并根据相同作者输入生成新四卡；不选卡、不采纳、不修改生产数据。fixture 明确标注为只读复制的真实生成小说候选。普通回归中的模型判断是明确标注的 TEST/SIMULATED 数据，仅验证证据与状态契约，不作为文学质量证明。


## 本轮工程验证与真实评估边界

原四卡来自生产数据库只读复制，原卡内容逐项比对均未改变。本轮把样例问题转换为跨题材规则与生成阶段，不将样例剧情写成固定模板。定向回归覆盖输入隔离、作者明确保留、多卡融合、不可变卡片、证据引用、关键缺口阻断、有限修订、叙事与摘要分离、转折来源、叙事断点恢复和局部事件保留。

## 双向关系与互动后续（2026-10-10）

新增统一关系创作规则 relationshipDesign.ts，经人物规则接入独立抽卡、大纲规划、正文生成、改写、篇幅调整和叙事审查；情节规则同时要求关系互动参与事件因果。重点是双方各自的需要与理解、靠近或留下的理由、专属相处规则和边界，以及行动被怎样理解、引起怎样的回应、怎样影响下一次选择。亲近、信任、尊重、依赖、权力和边界可分别变化；一次救援或道歉不自动清除历史。关系允许快乐、稳定、疏远和理解后的分开，不强制创伤、恋爱、和解或双方责任对半。

沿用 relationships.note、choiceReason、choice/consequence、growth/arc 等现有字段，不增加强制表单或评分；重要配角仍有独立目标、拒绝理由和相互联系。抽卡审查沿用 characterProcess、promisePayoff、lastingConsequences 检查点，仅重要承诺或关键行为因果缺口阻断，普通相处细化建议为 editorial。创作范围和已确认作品的事实保护仍分别处理，不改已保存人物、原卡或正文。
